# 美的仓储自动化控制台 (Desktop Assistant)

本套件为 **美的仓储对账流水线** 的桌面客户端工具，集成了「手动拉取物料邮件」、「自动按月归档」、「一键唤醒 GitHub Actions 流水线」与「快捷键秒开」功能。

---

## 一、 功能特性

1. **📥 手动下载最新物料邮件与附件**
   - 自动连接 QQ 邮箱 IMAP 服务器，检索最近邮件中包含关键词【**物料情况**】的最新邮件；
   - 自动解析时间戳并提取 HTML 正文与 Excel 附件；
   - **智能按月份归档**：根据邮件接收月份自动归档到对应 `YYYYMM`（如 `202610`）子文件夹中；若目标文件夹不存在则自动创建。

2. **🚀 一键触发 GitHub Actions 流水线**
   - 调用 GitHub API 唤醒 `huozao/meidi-auto` 的 `run-daily.yml` 主流水线；
   - 使用配置的 Classic Token 发送 `workflow_dispatch` 指令，状态码 204 即表示成功触发；
   - 即使家里库存文件缺失，也会容错触发降级发信通报。

3. **📂 秒开当月归档文件夹**
   - 采用 Windows 原生异步分发接口，毫秒级直接定位到当前月份的附件存放目录，杜绝界面假死与卡顿。

4. **✨ 现代极简流光 Fluent 图标与全局快捷键**
   - 配套多分辨率 Windows 官方标准图标（包含 16×16 至 256×256 高清 DIB+PNG 混合格式）；
   - 支持全局快捷键 **`Ctrl + Alt + M`**，在任何界面随时一键呼出控制台；
   - 纯 GUI 模式（`.pyw`）启动，完全不弹任何 PowerShell 或命令行黑框窗口。

---

## 二、 新电脑快速部署与使用指南

其他电脑克隆本仓库后，只需简单两步即可完成本地部署：

### 1. 配置环境变量
复制本目录下的配置模板：
```bash
cp .env.example .env
```
用文本编辑器打开 `.env`，填入对应账号与密钥：
- `QQ_EMAIL`：接收物料邮件的 QQ 邮箱
- `QQ_AUTH_CODE`：QQ 邮箱的 IMAP 授权码
- `SAVE_DIR`：附件下载存放路径（例如本地某个文件夹）
- `GITHUB_TOKEN`：具备 repo / workflow 权限的 GitHub Token

*(注：亦可在打开软件后，在界面点击【⚙️ 配置与使用说明】直接图形化修改并一键保存)*

### 2. 一键创建桌面快捷方式与图标
在当前目录下双击运行：
👉 **`install_shortcut.bat`**

安装程序会自动：
- 识别当前电脑上的仓库绝对路径；
- 在当前电脑桌面上生成带有专属极简流光 “M” 图标的 **`美的对账助手`** 快捷方式；
- 自动注册全局快捷键 **`Ctrl + Alt + M`**；
- 自动刷新 Windows 桌面图标缓存并秒开控制台。

## 三、 文件结构说明

| 文件 | 说明 |
| :--- | :--- |
| `meidi_console.py` | 控制台核心程序（包含 Tkinter 现代卡片 GUI 与 CLI 终端双模式） |
| `meidi_console.pyw` | 纯 GUI 运行入口（Windows 原生静默启动，零控制台黑框） |
| `install_shortcut.bat` | 一键桌面快捷方式安装器（跨电脑自动定位路径并绑定快捷键） |
| `app_icon.ico` | 现代极简流光 “M” 多分辨率标准 Windows 图标 |
| `app_icon.png` | 256×256 高清透明预览原图 |
| `.env.example` | 环境变量配置模板 |
| `.gitignore` | 本地凭据防泄漏规则（防止 `.env` 与 `config.json` 误提交） |
